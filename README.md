# Alí Ochoa · Presskit 3D

Presskit y plan de trabajo de Alí Ochoa (lo-fi, R&B y hip hop). Web estática con recorrido 3D por scroll hecho con Three.js.

- `index.html`: página
- `scene.js`: escena 3D y animaciones
- `art.js`: arte incrustado (avatar e ilustración)

Three.js y las tipografías se cargan desde CDN, así que hace falta conexión.
